Which release a feature was marked released in, and which one it was marked deprecated or dropped in. All of it is already in the repo: the status field is the lifecycle, git records when it changed, and a tag says which release that commit went out in. Says marked released in v0.2.0 rather than shipped in v0.2.0, because chocks cannot see the code that implements a feature, only when the claim about it changed. Needs statuses to declare what they mean, since the ids are project-defined and released could just as well be called shipped.
